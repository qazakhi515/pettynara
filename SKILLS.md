# Pettynara Project Skills

Use these Codex skills for repeatable Pettynara workflows.

Skill  
Purpose
==
`backend-cleanup` Continue Pettynara backend cleanup while preserving the current Express REST API architecture.

`frontend-cleanup` Continue Pettynara React cleanup while preserving existing React/Redux/Axios patterns.

`product-logic` Review pet product schema, enum, filter, REST API, and UI naming consistency.

`api-compatibility` Ensure frontend Axios calls match backend REST endpoints and response shapes.

Each skill lives at `skills/<skill-name>/skill.md`.
